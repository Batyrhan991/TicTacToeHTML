# Крестики-нолики (Tic-Tac-Toe)

Классическая браузерная игра "Крестики-нолики", созданная на чистом HTML, CSS и JavaScript.

## Особенности
- Современный адаптивный дизайн с эффектом стекломорфизма (Glassmorphism).
- Подсчет очков для игрока X, игрока O и ничьих.
- Интерактивные ходы с подсветкой и анимацией.
- Кнопка сброса текущей партии.

## Как запустить
Просто откройте файл `index.html` в любом современном веб-браузере.
